# 배뷰 BAEVIEW

### 달리는 하루, 더 선명하게.

복잡한 배달 업무는 가볍게, 눈앞의 길에는 더 집중할 수 있도록. **배뷰(BAEVIEW)**는 라이더의 경로 안내, 배달 업무 흐름과 운행 기록을 돕는 Android 기반 독립 서비스입니다.

## 라이더를 위한 핵심 기능

**스마트 경로 안내** — 지도와 목적지 안내로 운행 흐름을 간결하게 확인합니다.

**쿠팡이츠·배민 업무 보조** — 서로 다른 배달 플랫폼의 주문 상태를 독립적으로 파악하도록 돕습니다.

**운행 기록과 통계** — 지나온 운행과 수입 기록을 다시 확인할 수 있습니다.

**현장 제보와 개선** — 실제 라이더의 경험을 반영해 기능을 개선합니다.

*소개된 기능은 테스트 단계이며 앱 버전 및 이용 환경에 따라 달라질 수 있습니다. 쿠팡이츠·배달의민족과 공식 제휴 또는 인증된 서비스가 아닙니다.*
