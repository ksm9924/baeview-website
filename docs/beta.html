배뷰는 실제 라이더의 사용 경험을 바탕으로 기능을 개선하고 있습니다. Android 배달 라이더의 신청을 받고 있으며, 운영자가 신청 내용을 확인한 뒤 알파 테스트 참여 방법을 안내해 드립니다.

알파 참여 안내

  • Android 기기를 사용하는 배달 라이더를 대상으로 테스트를 진행합니다.
  • 참여하려면 알파 테스트 대상으로 등록된 Google 계정이 필요합니다.
  • 실제 현장에서 발견한 문제와 개선 의견은 앱 내 제보 기능 또는 운영 채널을 이용해 주세요.
  • 테스트 기능은 변경될 수 있으며, 운행 중 조작은 안전한 장소에서 진행해 주세요.

신청서에 Google Play에서 사용하는 이메일을 적어 주세요. 참여 안내를 받은 뒤 해당 계정으로 설치할 수 있습니다. 제보 해주신 내용은 먼저 반영합니다.
